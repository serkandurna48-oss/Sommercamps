# Design-Bestandsaufnahme SaaS, 25.09.2026

**Abgrenzung und Evidenz.** Gegenstand sind ausschließlich die SaaS-Routen unter `/pilot/[org]`, `/pilot/style-preview` und `/platform` sowie `backend_saas`/SaaS-Migrationen. Das Altsystem (`/`, `/admin`, `NEXT_PUBLIC_ACTIVE_CLUB`) ist aus A–D und F ausdrücklich ausgeschlossen; E vergleicht nur mit dem umbenannten Legacy-Audit. Dies ist eine Quellcodeprüfung. Eine nutzbare Browser-/Playwright-Sitzung mit beiden SaaS-Vereinen, Backend und Testdaten lag für dieses Nur-lesen-Audit nicht vor. Es gibt daher keine Screenshots und keine Aussagen über tatsächlich gesehene Pixel oder tatsächlich aufgetretenen Überlauf bei 375 px. Mobilbefunde sind statische Ableitungen. Die SaaS-Seite verwendet die getrennte API und einen DB-Mandanten, nicht den Build-Schalter des Altsystems. `frontend/app/pilot/[org]/page.tsx:35`, `frontend/app/pilot/[org]/page.tsx:50`, `frontend/app/platform/(console)/layout.tsx:12`.

**Maßstab.** Schweregrad 0 = kein Verstoß belegt, 1 = gering, 2 = merklich, 3 = erheblich, 4 = blockierend; `—` = Inventar oder Messung ohne Verstoß. Nielsen-Einträge nennen ausschließlich Verstöße. Kontraste sind aus den Hexwerten im Code nach WCAG 2.x relativer Luminanz berechnet, auf zwei Stellen gerundet. Normaltext braucht 4,5:1, Großtext 3:1. Die angefragten 44 × 44 CSS-px sind WCAG **2.1 AAA** (2.5.5), nicht AA; hier zusätzlich als Touch-Maßstab geprüft. Eine sichtbare Fokusregel im CSS ist ein Codebefund, kein durchgeführter Tastaturtest. `frontend/app/lib/brandPipeline.ts:66`, `frontend/app/lib/brandPipeline.ts:76`, `frontend/app/lib/brandPipeline.ts:85`, `frontend/app/components/saas/ui/Button.tsx:12`.
